SIMFAQ V563 - PENGINGAT SHOLAT TERPADU

Isi paket:
- index.html : HTML aplikasi V563
- sw.js      : Service Worker V5 dari paket V562 (tidak diubah pada revisi tampilan ini)

Perubahan V563:
1. Hitung mundur sholat ditampilkan di dalam tombol Pengingat Sholat yang sudah ada.
2. Tidak ada tombol atau panel hitung mundur terpisah.
3. Format hitung mundur: jam, menit, detik.
4. Hitung mundur diperbarui setiap detik dan mengikuti zona waktu serta penyesuaian jadwal tersimpan.
5. Informasi waktu jadwal ditampilkan lebih kecil agar tombol tetap ringkas.

Publikasi:
Unggah index.html dan sw.js ke direktori PWA yang sama pada hosting aplikasi. Revisi frontend belum otomatis terbit ke hosting hanya dengan mengunduh paket ini.

Catatan:
Service Worker V5 tetap disertakan apa adanya. Tidak ada perubahan database atau data peserta.
